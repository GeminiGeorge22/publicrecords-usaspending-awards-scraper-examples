# USAspending Awards Scraper — 예제

미국 연방 계약·보조금 수여 실적: 기관, 수혜자, NAICS, 기간.

이 Actor는 **본인** Apify 계정(API 토큰 또는 OAuth)에서 실행됩니다. 사용 요금은 Apify 무료 또는 유료 요금제에서 본인에게 청구됩니다.

## 링크
- [Apify Store 페이지](https://apify.com/publicrecords/usaspending-awards-scraper)
- [Apify MCP 엔드포인트](https://mcp.apify.com?tools=publicrecords/usaspending-awards-scraper)
- [n8n / Make / Zapier / Pipedream 레시피](https://github.com/GeminiGeorge22/publicrecords-mcp/tree/main/templates)
- [공개 스냅샷 데이터셋 (Hugging Face)](https://huggingface.co/datasets/Publicrecords/us-federal-contract-awards-top100)

## 동기 실행

`APIFY_TOKEN`에 본인의 Apify 토큰을 설정하세요. 저장소에 커밋하지 마세요.

```bash
export APIFY_TOKEN=YOUR_TOKEN
python3 examples/python/run.py
# node examples/javascript/run.js
# bash examples/curl/run.sh
```

Python, JavaScript, curl 예제는 `examples/`에 있습니다. 작성자: Public Records. 라이선스: MIT. 이 저장소에는 GitHub Actions가 없습니다.
